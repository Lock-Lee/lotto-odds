# เช็กโอกาสหวย

เว็บแอป React สำหรับดูโอกาสถูกสลากกินแบ่งรัฐบาล และตรวจสถิติย้อนหลังตั้งแต่ปี 2550 (471 งวด ถึงงวด 1 ตุลาคม 2569)

แอปนี้ไม่ได้ทำนายเลข ทุกเลขมีโอกาสออกเท่ากันทุกงวด ส่วนสถิติมีไว้แสดงว่าสูตรต่าง ๆ ไม่ได้ให้ผลดีกว่าการเดาสุ่ม

## วิธีรัน

ต้องมี Node.js 18 ขึ้นไป

```bash
npm install
npm run dev      # เปิด http://localhost:5173
npm run build    # ได้ไฟล์พร้อมอัปโหลดในโฟลเดอร์ dist/
```

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `src/data.js` | ผลรางวัลที่ฝังมากับแอป งวดละ 1 บรรทัด |
| `src/update.js` | ดึงงวดใหม่อัตโนมัติจาก GitHub |
| `src/logic.js` | การคำนวณ: ความถี่ ไคสแควร์ ทดสอบสูตรย้อนหลัง เช็กเลข |
| `src/App.jsx` | หน้าจอทั้ง 5 เมนู: เช็กเลข เลือกเลข โอกาส สถิติ ย้อนหลัง |
| `src/style.css` | สีและเลย์เอาต์ รองรับโหมดมืด |

## การอัปเดตงวดใหม่

แอปตรวจหางวดใหม่เองทุกครั้งที่เปิด (ไม่ถี่กว่าทุก 6 ชั่วโมง) โดยดึงจากชุดข้อมูล thai-lotto-archive บน GitHub แล้วเก็บไว้ในเบราว์เซอร์ของผู้ใช้ โค้ดอยู่ใน `src/update.js`

- งวดใหม่จะขึ้นในแอปหลังจากเจ้าของชุดข้อมูลต้นทางอัปเดตแล้วเท่านั้น
- ถ้าขอรายชื่อไฟล์จาก GitHub API ไม่ได้ (โควตา 60 ครั้งต่อชั่วโมงต่อ IP) แอปจะลองดึงไฟล์ตามวันออกรางวัลที่เป็นไปได้แทน
- ถ้าดึงไม่สำเร็จเลย (ออฟไลน์หรือต้นทางล่ม) แอปใช้ข้อมูลที่มีอยู่ต่อไป และแจ้งไว้ท้ายหน้า
- งวดที่รางวัลยังไม่ครบหรือรูปแบบผิดจะถูกข้าม

ถ้าต้นทางหยุดอัปเดต ให้เพิ่มงวดเองโดยต่อบรรทัดท้ายสุดใน `src/data.js` ตามรูปแบบ

```
"วันที่ ค.ศ.|รางวัลที่ 1|เลขท้าย 2 ตัว|เลขหน้า 3 ตัว (2 เลขติดกัน)|เลขท้าย 3 ตัว (2 เลขติดกัน)"
"2026-10-01|402701|70|791912|058396"
```

## ที่มาของข้อมูล

ชุดข้อมูล [thai-lotto-archive](https://github.com/vicha-w/thai-lotto-archive) ซึ่งรวบรวมจาก sanook.com และ kapook.com งวด ม.ค. 2564 – ต.ค. 2569 เทียบกับ lottery.co.th แล้วตรงกัน งวดก่อนหน้านั้นส่วนใหญ่อ้างอิงจากชุดข้อมูลแหล่งเดียว ไม่ใช่เอกสารทางการของสำนักงานสลากกินแบ่งรัฐบาล
